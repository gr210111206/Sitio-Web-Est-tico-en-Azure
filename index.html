Acerca de la práctica

Este sitio forma parte de la práctica de laboratorio de Administración de Cómputo en la Nube. El objetivo es configurar un entorno de almacenamiento en la nube para hospedar un sitio web estático y automatizar su despliegue con integración y entrega continua.

🌐 Hospedaje en la nube

Servido desde Azure Static Web Apps, altamente disponible y escalable.

🔁 Despliegue automático

Cada push a la rama main actualiza el sitio sin intervención manual.

💰 Costo optimizado

Más rentable que una máquina virtual: se paga solo por almacenamiento y tráfico.

Flujo CI/CD

  1. Commit & Push del código a GitHub.
  2. GitHub Actions detecta el cambio en main.
  3. Build de los artefactos estáticos.
  4. Deploy automático hacia Azure.
  5. URL pública actualizada al instante.
